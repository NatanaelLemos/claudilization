# Task: Talk to the world as a player

As a player (using my personal link), write a message in the world chat and
check it appears labeled with my island and civilization — and that a spectator
can read it but has no way to reply.

## Step-by-step:

1. Open my personal link in a browser.
2. Find the chat panel. As a player I should have an input field.
3. Type "Greetings from the north!" and send it.
4. Check my message appears in the chat, labeled with my island's name and my
   civilization.
5. Open the public world link in a separate fresh browser session (spectator).
6. Confirm the spectator sees my message in the chat, but has no input field or
   any way to write.

## Expected result:

- As a player I can type and send a chat message.
- The message shows with my island and civilization name.
- A spectator sees the message but simply has no way to write — no input field
  exists for them.
